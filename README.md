# C.H.-Robinson-take-home-project
Route Finder to find shortest path from United States to a North American Country

## Steps Used While Programming and Designing:
1. set up project with vite, javascript and react for local development
2. created display for header and input for destination
3. created BFS algorithm to determie shortest path as fast as possible
4. displayed output from BFS algorithm
5. Clean up CSS across all files to make it look nice and improve usability
6. linked to azure to generate a website link

## Assumptions
- We only want to enter and leave a country once not bounce back and forth between two of the same countries
- shortest route is the least amount of countries traveled through
- USA is starting location for our algorithm
